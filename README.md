#Python Calculator

A simple command-line calculator built with Python on Arch Linux. This is a project for practice programming, Git and Github

##Features

-Addition
-Subtraction
-Multiplication
-Division
-Square of number
-Modulus
-Division-by-zero error handling
-Invalid operator handling

##Requirements

-Python3

##How to run

1. Clone or download this repository.
2. Open a terminal in project directory.
3. Run the calculator
